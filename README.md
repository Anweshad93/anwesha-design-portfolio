# Anwesha Das — AI for Interdisciplinary Design Portfolio

An interactive design portfolio featuring two projects:

- **Training Season** — an album-cover concept with final artwork, process comparison, and sound.
- **Design Future Studio** — a 3D environment concept with a camera walkthrough.

The homepage includes a click-and-tap drawing area that creates a new organic shape and transforms the existing composition.

## View locally

Open `index.html` in a browser, or serve this folder with any static web server.

## Publish

This site is ready for GitHub Pages. Publish from the repository's `main` branch and `/ (root)` folder.
